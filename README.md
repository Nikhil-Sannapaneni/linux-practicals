# Linux Security Practicals

A hands-on Linux security learning repository focused on skills relevant to a junior SOC Analyst / Blue Team role.

## Objectives

- Build confidence with Linux command-line administration
- Understand users, groups and file permissions
- Practise process and service investigation
- Analyse Linux authentication and system logs
- Secure remote access with SSH
- Write basic Bash scripts for security tasks
- Document investigations clearly

## Lab Environment

These practicals are designed for a Linux virtual machine or lab environment. Commands should be tested in a disposable lab system before being used on production systems.

## Structure

- `users-permissions/` — users, groups and permissions
- `ssh-security/` — SSH configuration and investigation
- `log-analysis/` — authentication and system log analysis
- `processes-services/` — process and service investigation
- `bash-scripts/` — small security automation scripts
- `notes/` — learning notes and investigation write-ups

## SOC Relevance

Linux skills are useful for SOC analysts when investigating authentication events, suspicious processes, persistence, privilege changes, and system activity.

## Learning Approach

Each practical records:

1. Objective
2. Environment
3. Commands used
4. Expected output
5. Security interpretation
6. Lessons learned

> This repository is for defensive learning and authorised lab environments only.
